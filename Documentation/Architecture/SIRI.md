# Siri and App Intents

Moved verbatim from `Cosmic Daybook/CLAUDE.md` on 2026-10-02 so that file keeps only the rules every session needs. Dates in the notes are when each change landed.

## Siri (App Intents)

- **Attendance by voice in both apps (2026-09-29):** "Mark Maya here / late / absent", "Undo attendance" (`Siri/AttendanceIntents.swift`), plus the Assistant's "Close arrival" and "Who's not here yet" (`Daybook Assistant/Siri/AssistantAttendanceIntents.swift`). Every mark goes through `SiriAttendance` → `CDAttendanceStore`, the grid's path. Here and late run on a locked phone (`.alwaysAllowed`); absent, undo, close arrival and who's-missing need the phone unlocked (undo can put back an absent mark or a whole Close Arrival, so it asks as much as they did). Close arrival and who's-missing act on the grid's day roll (`AssistantDayRoll`), never every enrolled child; their work is in `AssistantSiriCommands` and "here" is `SiriAttendance.markHere`, so tests run them in memory. The Assistant names children as its grid does ("Maya", "Etty G") and never resolves a former student (`SiriHost.displayNames` / `formerStudents`); the notebook keeps full names, falls back to former students only when no one on the roll has the name, never to test students, and not at all on a locked iPhone. "Here" after arrival has closed marks tardy in both apps, but never downgrades a child already present: closed on that device (`AttendanceLatePhase`, set by Close Arrival on the Assistant's grid or the notebook's roll), and in the notebook also closed anywhere else, seen as Close Arrival's automatic absence on a record that day (`CDAttendanceStore.arrivalClosed`). The Assistant's roll and Siri roster hide the notebook's default test-student names (`TestStudentsFilter`, compiled by path) and show a student synced twice once. **Undo (2026-09-29):** a reason-only change ("absent, sick" on a child already absent) puts the stored reason back, Close Arrival's automatic marker included; a locked day refuses the undo and keeps it; closing arrival on the grid retires Siri's older change. Leave (here or on another of her iPhones, which now sends this one back to joining) and Rebuild from iCloud forget the Late days, the undo memory and the sync line's times (`AssistantClassroomLocalState`). Once CloudKit mirroring stops mid-attach, `AssistantShareAttacher` tries nothing more on that container (`ShareAttachResult.mirroringStopped`); the marks wait for a rebuilt stack or relaunch.
- **One attendance grid, two apps (2026-09-30):** the Assistant's rules and tile live in `Cosmic Daybook/Attendance/` and join the Assistant by path: `AttendanceRules` (tap, day-ahead, who marked, tallies, mark times), `AttendanceRow`, `AttendanceBirthday`, `AttendanceClock`, `AttendanceLatePhase` (keys still `Assistant.latePhaseDays`), `AttendanceGridNames`, `AttendanceDaySwipe`, `AttendanceStatusMenu`, `Tile/AttendanceTile*` (iOS only), and since 2026-09-30 the Assistant's delights: `AttendanceWelcomeBack` (a child absent 3+ school days waves, "Welcome back, Maya"), `AttendanceSchoolDayCount` ("Day 37", First Day, Day 100, counted from the year's first here-mark since July 1 in both apps so they agree), `HundredthDayConfetti`, `AttendanceBells` (iOS only; each app its own `Assistant.bellsOn` default, off) and `SeededRandom`. The notebook's iPhone roll is that tile grid (`AttendanceTileGrid`); since 2026-10-01 the Mac and iPad draw `AttendanceCard` in the same tile language (here filled green, not in yet empty, absent dashed, Late an amber ring) and a click does what the tap does (`statusAfterTap`; the old click-cycle is gone), grouped by level when the synced `Attendance.groupsByLevel` is on (`AttendanceLevelGroups`, shared with the Assistant), with keyboard selection, Space to mark and type-to-jump. Above the tiles, `AttendanceExpandedView+Band` shows "17 of 22 here", where arrival stands and the one button the moment calls for (Close Arrival & Email… near the due time, Close Arrival…, Email Front Desk), Not in yet, and the day's pickups/departures/returns; View, the lock and More sit in the Attendance toolbar (`+Controls`). Mark N Present marks only the unmarked (it used to overwrite late/absent/left-early marks) and every mark from the roll is on ⌘Z with Redo (`AttendanceViewModel+Undo`). `AttendanceViewModel` owns the day's roll as value rows, Close Arrival and Reset Day, each with an Undo in the toast; ahead of the day only absences and notes are taken (screens and view model, not the store, so MCP and restore are unchanged).
- **Shared by path, one seam:** the student entity, `StudentNameMatcher`, `SiriAttendance`, the undo memory, `SiriSyncKeepAlive` and the attendance intents compile into both apps. They reach the app only through `SiriHost`, which each target defines with the same shape (`Siri/SiriHost.swift`, `Daybook Assistant/Siri/AssistantSiriHost.swift`). The Assistant builds its one stack in `AssistantStack` so a Siri launch with no window never opens a second container. Shared files target iOS 18: no iOS 26+ App Intents API in them without an availability check.
- **Apple's limit is 10 App Shortcuts per app, and the notebook is at 10.** The four "Open Today/Students/Lessons/Attendance" intents became one `OpenSectionIntent`; the old ones stay (`isDiscoverable = false`) so saved shortcuts keep running. Adding an App Shortcut means merging another.
- **Names reach Siri only through `updateAppShortcutParameters()`**: the notebook calls it on each launch's Spotlight pass, the Assistant whenever its roster changes (`AssistantSiriVocabulary`). Phrases must include the app name; for a bare "Mark Maya here" the user makes a personal Shortcut with that name.

## Rules (moved from CLAUDE.md, 2026-10-04)

Moved verbatim from `Cosmic Daybook/CLAUDE.md` on 2026-10-04 so that file keeps only a pointer and the few rules a session needs before touching this area. These are still rules: follow them.

Attendance by voice in both apps (`Siri/AttendanceIntents.swift`, `Daybook Assistant/Siri/AssistantAttendanceIntents.swift`). Details: `Documentation/Architecture/SIRI.md`.

- Every mark goes through `SiriAttendance` → `CDAttendanceStore`, the grid's path.
- Files the Assistant compiles by path reach the app only through `SiriHost` and must build for iOS 18.
- **Apple allows 10 App Shortcuts per app, and the notebook is at 10 (the Assistant at 9);** adding one means merging another. Retired intents stay, with `isDiscoverable = false`, so saved shortcuts keep running.
- Names reach Siri only through `updateAppShortcutParameters()`.
